## 4. 誤判定と訂正
- r071P「三角関数は的外れ」→ 極座標/方向弾は角度が毎フレーム変わりキャッシュ常時ミス、全体の呼出減を該当経路と混同。r072P で DfSinCosReduced 756命令の直列鎖＝変形弾 9.6µs と確定(T8:310-312,BUD§38)
- r087「計測税」→ 全phase 1.4〜1.6倍＝クロック差。ARK の OC は API の clock 値に出ない(T8:83,121,290)
- 「音声が主犯」→ flip guard 待ちが Calc に計上(T8:113)
- 「443 OC が30秒停止の原因」→ 423でも再発、ef0 極小read(T8:121-123)
- Xperia「FBO がドライバ固有に遅い」→ uniform 分岐1本シェーダ(X)
- 「60モード率97.7%」→ 密集窓の実速度 43〜46Hz(T8:377)

## 5. 計測と進め方の教訓
- 判定は SIM_CHECK/SYNC_TRACE 一致＋同一リプレイ同一窓 A/B、1 run 1判定。クロックは cal_us で確認し、1点＋推論で断定しない（TH07「ME は OC しない」の誤り, T8:85,T7:153）
- PPSSPP はキャッシュミスを映さない（実機/P 比 pu 6.8×, T8:103）。件数は P、実機は時間だけ。「P で不再現」は不採用根拠として弱い(T8:365)
- 暖機ベンチ≠ループ内（記憶 miss 2.5 vs 4.6〜5.5µs）、同じ仕事でも配置で calc ±40%(T8:369,372)
- 計測器が遅くする: TH07 ATTRIB 1.6倍(T7:46)、ログ flush で1.9秒停止(T8:360)。指標は MISS/N と実速度、TH07 の走行間ノイズ ±0.01fps(T7:156)
- 計測専用版禁止、実機依頼は手順1つで何かを決める版だけ、作る前に節約上限(CHK§E)

## 6. 風神録への当てはめ（Go 描画 30 と Xperia 描画 30、それぞれ最初に打つべき手 5 個）
前提: TH10 は libm sin/cos 最大3,635回/tick(TH10)。Go@423 単価は sin64+cos64 43.6µs・DF miss 3.1・記憶 hit 0.7(T8:367)→libm のままだと最悪 tick ≈160ms（掛け算、TH10 実測ではない）。
**Go 描画30（423固定）**
1. 初版から窓計測（calc1/calc2/draw/vblank・MISS・cal_us）と RAM ログ。予算参照は永夜抄 Go@423 密集 1tick≈22ms（calc7.2+draw6.6+present2.8+未帰属5.7, T8:377）
2. 永夜抄の DF 経路（節点表・lean・整数tail・物体ごと記憶）を移植。受理判定は (f32) 丸め前提で、float に丸める箇所なら描画側も bit 同一(T8:91)。回転不変の絵は角度変化時だけ計算(T8:69)
3. GE 直叩きは zero-copy＋draw ごと公開＋フェンス付きリング(GE:85-102)、16bit/CLUT8（DXT 禁止）、送出を減らす（1回≈40µs, T8:354）。roundToInt は cvt.w.s 近道＋監査（199→45ns, T8:355）。SoftFloat の PSP 単価は記録なし
4. ペーシングは covered 分の vblank を丸ごと待つ（r262 前は1vblankに2tick、TICK_SPIKE 761→0, T8:363,367）。ガードは色書込み直前、非同期 flip 禁止、トリプルは Present=GE フェンス依存を消してから(PV,T8:162)
5. ME は音声 MECC だけ(AME)。フォント等は起動時 RAM 常駐（ef0 停止, EF0）
**Xperia 描画30**
1. 永夜抄 Android 層の仕様（全解像度・draw_rate=30・60tick/s・max_skip=2）を流用、MISS は swap 間隔か追加スキップ数で数える(X)
2. uniform 分岐1本シェーダを状態キー別変異へ（必須、15→59fps, X）
3. SET_BUFFER_COUNT=3、win565・深度無し(+6)、early_present(+4)、atest_zwrite(+3)(AND§7)。FBO 経由 640x480 は 42.7 vs 窓直描き 55.0fps(X)
4. 毎 draw glBufferData・全面再転送・glReadPixels(197ms)を作らない(AND§8-9)。CPU は TH07 SO-02C で draw 5.4＋calc 4.4＋swap 3ms(AND§7)。TH08 の状態重複除去等の効果は記録なし
5. 3D 背景は同次座標＋24bit深度(X)。律速は塗り（全解像度の反魂蝶 33〜37fps）。ARM の libm/SoftFloat 単価は記録なし→初版で測る
