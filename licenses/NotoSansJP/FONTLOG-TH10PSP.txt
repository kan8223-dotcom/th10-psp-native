HarfBuzz 12.3.0), fontTools 4.62.1 (only to look up the character map).

Modification summary:

- keep only the 1,124 characters TH10's texts use (the Shift_JIS codes in
  charset_th10.bin that decode as CP932);
- render each at 32 px into an 8-bit coverage bitmap, using the half-width
  forms (OpenType 'hwid') for single-byte codes and the full-width forms
  ('fwid') for double-byte codes;
- place the glyphs on MS Gothic's metrics, which the game's text layout
  assumes: advance 16 or 32 px, baseline 28 px below the line top;
- store them in the "T10F" table layout the game reads. No outlines, hints,
  layout tables or names are kept.

Other library versions may rasterize some pixels differently. The release
uses the bytes above; tools/release/build_release.sh and
tools/unified/check_no_original_assets.py check them by SHA-256.
